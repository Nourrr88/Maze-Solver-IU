Smart Maze Solver Using BFS

فكرة المشروع:
المشروع ده عبارة عن برنامج بسيط بيحل المتاهة.
المستخدم يقدر يعمل حوائط ويحدد نقطة البداية ونقطة النهاية، وبعد كده البرنامج يدور على أقصر طريق بينهم.

الأدوات اللي استخدمناها:
- Python 3
- Tkinter عشان نعمل الواجهة الرسومية
- BFS عشان نحل المتاهة

طريقة تشغيل البرنامج:
1. لازم يكون Python 3 متسطب على الجهاز.
2. نحط ملف README.txt مع ملف CF321_Smart_Maze_Solver_Final.py.
3. نفتح PowerShell في نفس مكان الملف.
4. نكتب الأمر ده:

python CF321_Smart_Maze_Solver_Final.py

طريقة استخدام البرنامج:
1. نضغط على Wall ونضغط على الخلايا اللي عايزين نعملها حوائط.
2. نضغط على Start ونختار خلية البداية.
3. نضغط على Goal ونختار خلية النهاية.
4. نضغط على Solve with BFS.
5. البرنامج هيظهر الخلايا اللي جربها وأقصر طريق.

معنى الألوان:
- الأخضر هو مكان البداية.
- الأحمر هو مكان النهاية.
- الأزرق هو الخلايا اللي البرنامج استكشفها.
- الأصفر هو أقصر طريق.
- الأسود هو الحائط.

فكرة BFS ببساطة:
BFS بتبدأ من نقطة البداية وتجرب الخلايا القريبة الأول، وبعد كده الخلايا الأبعد.
عشان كده لما كل حركة تكلفتها 1، الخوارزمية بتجيب أقصر طريق.

البرنامج بيعرض كمان:
- هل فيه طريق ولا لأ.
- عدد الحركات.
- تكلفة الطريق.
- عدد الخلايا اللي اتجربت.

لو مفيش طريق، البرنامج هيقول إن مفيش Path بسبب الحوائط الموجودة.
