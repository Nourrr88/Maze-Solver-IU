# Smart Maze Solver Using BFS

## فكرة المشروع

المشروع ده عبارة عن برنامج بسيط بيحل المتاهة. المستخدم يقدر يعمل حوائط ويحدد نقطة البداية ونقطة النهاية، وبعد كده البرنامج يدور على أقصر طريق بينهم.

## 1. Problem Formulation

- **States:** كل خلية فاضية في المتاهة، ومكتوبة بالشكل `(row, column)`.
- **Start state:** الخلية اللي المستخدم بيختارها كبداية.
- **Goal state:** الخلية اللي المستخدم بيختارها كنهاية.
- **Actions:** الحركة لفوق أو لتحت أو يمين أو شمال، بشرط إن الخلية تكون جوه المتاهة ومش حائط.
- **Cost:** كل حركة تكلفتها `1`، وبالتالي تكلفة الطريق = عدد الحركات.

## 2. Algorithm

استخدمنا خوارزمية **Breadth-First Search (BFS)**.

الفكرة ببساطة إن BFS بتبدأ من البداية وتجرب الخلايا القريبة الأول، وبعد كده الخلايا الأبعد. البرنامج بيستخدم Queue عشان يحفظ الخلايا، وبيحفظ الـ parent عشان يرجع ويبني الطريق بعد ما يوصل للنهاية.

بما إن كل حركة تكلفتها 1، BFS بتطلع أقصر طريق. مش محتاجين Heuristic لأننا مش بنستخدم A* أو Greedy.

عشان نعمل Demo جاهز:

الأزرق هو الخلايا اللي البرنامج استكشفها، والأصفر هو أقصر طريق.

## الاستخدام العادي

- اضغط **Wall** ثم اضغط على الخلايا اللي عايز تعملها حوائط.
- اضغط **Start** ثم اختار خلية البداية.
- اضغط **Goal** ثم اختار خلية النهاية.
- اضغط **Solve with BFS**.
- اضغط **Clear Solution** لمسح الحل فقط.
- اضغط **Reset All** لمسح كل حاجة.

البرنامج بيعرض إذا كان فيه حل، أقصر طريق، عدد النقلات، تكلفة الطريق، وعدد الخلايا المستكشفة.
